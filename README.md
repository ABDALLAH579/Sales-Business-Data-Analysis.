# Sales & Business Data Analysis (EDA)

## Project Overview
Exploratory Data Analysis of sales and business data using Python.

## Tools & Technologies
- Python
- Pandas
- NumPy
- Matplotlib

## Project Tasks
- Data Exploration
- Data Cleaning
- Data Manipulation
- Missing Values & Duplicates
- Outlier Detection using IQR
- Data Visualization

## Objective
To analyze sales data, discover patterns,
and extract meaningful business insights.
